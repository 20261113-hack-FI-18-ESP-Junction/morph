                        None)
  --teleop str          Config file for teleop (default: None)

TeleoperateConfig:

  --fps int             Limit the maximum frames per second. (default: 60)
  --teleop_time_s [float]
  --display_data bool   Display all cameras on screen (default: False)
  --display_mode str    Visualization backend used when display_data is True:
                        "rerun" or "foxglove". (default: rerun)
  --display_ip [str]    For "rerun": IP of a remote server to send to. For
                        "foxglove": interface to bind the WebSocket server to
                        (127.0.0.1 for local only, 0.0.0.0 for all
                        interfaces). (default: None)
  --display_port [int]  For "rerun": port of the remote server. For
                        "foxglove": port to bind the WebSocket server to.
                        (default: None)
  --display_compressed_images bool
                        Whether to display compressed (JPEG) images instead of
                        raw frames (default: False)
